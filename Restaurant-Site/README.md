# Luna Table

## 企画・設計

### 店舗設定

- 店名：Luna Table
- 業態：イタリアンレストラン
- 場所：東京都内
- 客単価：¥3,000〜¥5,000
- ターゲット：20〜40代、カップル、友人同士、デート利用
- 特徴：自家製パスタ、季節の食材、ワイン、落ち着いた雰囲気

### サイトの目的

店舗の雰囲気や料理、店舗情報を伝え、
Webサイトから予約・来店につなげる。
